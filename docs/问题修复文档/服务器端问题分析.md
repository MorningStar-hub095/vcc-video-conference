# 服务器端问题分析报告

## 问题现象

客户端日志显示：
```
[DEBUG] slot_registerCommit 被调用, tel: "133133133"  name: "小明"
[DEBUG] 网络已连接，准备发送注册请求
f9b77d488ca8463fa2f8bdb44863159d   ← MD5 密码已生成
on_pb_commit_register_clicked       ← 信号已发射
                                    ← 这里就停了！服务器没有回复
```

客户端一切正常：槽函数被调用、正则校验通过、网络已连接、数据已发送。但**服务器没有返回任何回复**，所以没有提示框弹出，也没有跳转。

---

## 服务器端发现的问题

### 问题 1（致命）：协议映射表未初始化，导致所有请求都无法处理

**文件**：`服务器代码/src/TCPKernel.cpp` 第 11~27 行

```cpp
//设置网络协议映射
void TcpKernel::setNetPackMap()
{
    //清空映射
    bzero( m_NetPackMap , sizeof(m_NetPackMap) );

    //协议映射赋值
//        m_logic->setNetPackMap();        // ← 被注释掉了！
//        NetPackMap(DEF_PACK_REGISTER_RQ) =&TcpKernel::RegisterRq;
//        NetPackMap(DEF_PACK_LOGIN_RQ)    =&TcpKernel::LoginRq;
//        ...（全部被注释）
}
```

**问题分析**：
- `TcpKernel::setNetPackMap()` 中所有协议映射赋值都被注释掉了
- 虽然 `CLogic::setNetPackMap()`（在 clogic.cpp 中）有正确的映射赋值，但**从未被调用**
- 结果：`m_NetPackMap` 数组全为 0（NULL），`DealData` 函数中 `PFUN pf = NetPackMap(type)` 取到 NULL，`if(pf)` 判断失败，**所有请求包都被丢弃**

**数据流向**：
```
客户端发送 REGISTER_RQ
    ↓
服务器 recv_task 接收到数据
    ↓
服务器 Buffer_Deal 调用 m_recv_callback (即 DealData)
    ↓
DealData 中: PFUN pf = NetPackMap(type);  // pf = NULL
    ↓
if( pf ) 判断失败 → 不调用任何处理函数
    ↓
数据包被丢弃，服务器不回复任何内容
    ↓
客户端一直等待回复，表现为"毫无反应"
```

**修复方法**：取消注释 `m_logic->setNetPackMap();`

```cpp
//设置网络协议映射
void TcpKernel::setNetPackMap()
{
    //清空映射
    bzero( m_NetPackMap , sizeof(m_NetPackMap) );

    //协议映射赋值
    m_logic->setNetPackMap();   // ← 取消注释！
}
```

### 问题 2：CLogic::setNetPackMap 中音频注册映射被视频注册覆盖

**文件**：`服务器代码/src/clogic.cpp` 第 3~13 行

```cpp
void CLogic::setNetPackMap()
{
    NetPackMap(DEF_PACK_REGISTER_RQ)         =&CLogic::RegisterRq;
    NetPackMap(DEF_PACK_LOGIN_RQ)            =&CLogic::LoginRq;
    NetPackMap(DEF_PACK_CREATEROOM_RQ)       =&CLogic::CreateRoomRq;
    NetPackMap(DEF_PACK_JOINROOM_RQ)         =&CLogic::JoinRoomRq;
    NetPackMap(DEF_PACK_LEAVEROOM_RQ)        =&CLogic::LeaveRoomRq;
    NetPackMap(DEF_PACK_AUDIO_FRAME)         =&CLogic::AudioFrameRq;
    NetPackMap(DEF_PACK_VIDEO_FRAME)         =&CLogic::VideoFrameRq;
    NetPackMap(DEF_PACK_VIDEO_REGISTER)      =&CLogic::AudioRegister;   // ← 应为 DEF_PACK_AUDIO_REGISTER
    NetPackMap(DEF_PACK_VIDEO_REGISTER)      =&CLogic::VideoRegister;   // ← 覆盖了上一行
}
```

**问题分析**：
- 第 11 行和第 12 行都用了 `DEF_PACK_VIDEO_REGISTER`，第 12 行覆盖了第 11 行
- 音频注册（`DEF_PACK_AUDIO_REGISTER`）没有映射到处理函数
- 应该是第 11 行用 `DEF_PACK_AUDIO_REGISTER`

**修复方法**：
```cpp
void CLogic::setNetPackMap()
{
    NetPackMap(DEF_PACK_REGISTER_RQ)         =&CLogic::RegisterRq;
    NetPackMap(DEF_PACK_LOGIN_RQ)            =&CLogic::LoginRq;
    NetPackMap(DEF_PACK_CREATEROOM_RQ)       =&CLogic::CreateRoomRq;
    NetPackMap(DEF_PACK_JOINROOM_RQ)         =&CLogic::JoinRoomRq;
    NetPackMap(DEF_PACK_LEAVEROOM_RQ)        =&CLogic::LeaveRoomRq;
    NetPackMap(DEF_PACK_AUDIO_FRAME)         =&CLogic::AudioFrameRq;
    NetPackMap(DEF_PACK_VIDEO_FRAME)         =&CLogic::VideoFrameRq;
    NetPackMap(DEF_PACK_AUDIO_REGISTER)      =&CLogic::AudioRegister;   // ← 修复
    NetPackMap(DEF_PACK_VIDEO_REGISTER)      =&CLogic::VideoRegister;
}
```

### 问题 3：LoginRq 中 SQL 查询字段与 SelectMysql 参数不匹配

**文件**：`服务器代码/src/clogic.cpp` 第 75~85 行

```cpp
void CLogic::LoginRq(int clientfd, char * szbuf, int nlen)
{
   ...
   char strsql[1024] = "";
   list<string> lstRes;
   sprintf( strsql , "select tel from t_user where tel = '%s';",rq->m_tel);

   if(!m_sql->SelectMysql(strsql , 2 , lstRes))   // ← 参数 2 表示查 2 个字段
   {
       printf("SelectMysql error: %s \n",strsql);
       return;
   }
   ...
}
```

**问题分析**：
- SQL 语句只查了 1 个字段（`select tel`），但 `SelectMysql` 第二个参数传 2（期望 2 个字段）
- 后续代码 `lstRes.pop_front()` 取 id，`lstRes.front()` 取 name，但实际只查了 tel
- 应该查询 `id` 和 `name` 字段

**修复方法**：
```cpp
sprintf( strsql , "select id, name from t_user where tel = '%s' and password = '%s';",
         rq->m_tel, /*MD5密码*/);
```

注意：登录还缺少密码校验逻辑，原代码只查 tel 不查 password，且查到后直接返回 login_success，存在安全漏洞。

### 问题 4：数据库连接配置需确认

**文件**：`服务器代码/src/TCPKernel.cpp` 第 63~68 行

```cpp
m_sql = new CMysql;
// 数据库 使用127.0.0.1 地址  用户名root 密码****** 数据库 wechat
if(  !m_sql->ConnectMysql( _DEF_DB_IP , _DEF_DB_USER, _DEF_DB_PWD, _DEF_DB_NAME )  )
{
    printf("Conncet Mysql Failed...\n");
    return FALSE;
}
```

**需确认**：
- MySQL 数据库是否已启动
- 是否存在 `wechat` 数据库
- 是否存在 `t_user` 表（字段：id, tel, password, name, icon, feeling）
- 数据库用户名/密码是否正确（默认 root/******）

## 修复步骤

### 第一步：修复协议映射表（最关键）

打开 `服务器代码/src/TCPKernel.cpp`，找到 `setNetPackMap` 函数（约第 11 行），取消注释：

**原代码：**
```cpp
void TcpKernel::setNetPackMap()
{
    bzero( m_NetPackMap , sizeof(m_NetPackMap) );
//        m_logic->setNetPackMap();
//        NetPackMap(DEF_PACK_REGISTER_RQ) =&TcpKernel::RegisterRq;
//        ...
}
```

**修改后：**
```cpp
void TcpKernel::setNetPackMap()
{
    bzero( m_NetPackMap , sizeof(m_NetPackMap) );
    m_logic->setNetPackMap();
}
```

### 第二步：修复音频注册映射

打开 `服务器代码/src/clogic.cpp`，找到 `setNetPackMap` 函数（约第 3 行）：

**原代码：**
```cpp
NetPackMap(DEF_PACK_VIDEO_REGISTER)      =&CLogic::AudioRegister;
NetPackMap(DEF_PACK_VIDEO_REGISTER)      =&CLogic::VideoRegister;
```

**修改后：**
```cpp
NetPackMap(DEF_PACK_AUDIO_REGISTER)      =&CLogic::AudioRegister;
NetPackMap(DEF_PACK_VIDEO_REGISTER)      =&CLogic::VideoRegister;
```

### 第三步：确认数据库环境

1. 启动 MySQL 服务
2. 创建 `wechat` 数据库（如果不存在）
3. 创建 `t_user` 表（如果不存在）：
   ```sql
   CREATE DATABASE IF NOT EXISTS wechat;
   USE wechat;
   CREATE TABLE IF NOT EXISTS t_user (
       id INT AUTO_INCREMENT PRIMARY KEY,
       tel VARCHAR(20),
       password VARCHAR(64),
       name VARCHAR(20),
       icon INT,
       feeling VARCHAR(100)
   );
   ```
4. 确认数据库用户名密码与代码中一致（`_DEF_DB_USER`, `_DEF_DB_PWD`）

### 第四步：重新编译并启动服务器

在 Linux 虚拟机（192.0.2.129）上：
```bash
cd 服务器代码/src
make
./PlayerHallServer
```

启动后应看到：

## 修改一：LoginRq 登录请求处理（对应问题1：用户名乱码）

原代码中：
1. SQL 语句只查询了 `tel` 一列，但 `SelectMysql` 传入 `2` 列，导致数据读取错位

3. 没有验证密码就直接返回登录成功
4. 用户名 `m_userName` 取值错误，导致发送给客户端的是错误数据，显示为乱码

## 修改二：JoinRoomRq 加入房间处理（对应问题3：加入房间功能失效 + 房间号显示为0）

### 问题原因
原代码中：
1. **房间号未设置**：发送成功回复时没有设置 `rs.m_RoomID = rq->m_RoomID`，而 `STRU_JOINROOM_RS` 构造函数中 `m_RoomID = 0`，导致客户端界面 lb_title 显示"房间号:0"
2. `if( !m_mapIDToRoomid.IsExist(rq->m_UserID)) return;` —— 检查的是"房间ID的map中是否存在用户ID"，但 `m_mapIDToRoomid` 的 key 是 roomid 不是 userid！这导致几乎总是 return，加入房间的后续逻辑（互换成员信息）完全不执行。
3. 遍历成员列表时 `if( !m_mapIDToUserInfo.IsExist(Memid)) return;` —— 如果某个成员不在线就直接 return，导致后续成员信息不发送。

### 原代码（第 168-205 行附近）

```cpp
        //存在，返回成功
        rs.m_lresult = 1;
        SendData( clientfd , (char*)&rs , sizeof (rs));

        if( !m_mapIDToRoomid.IsExist(rq->m_UserID)) return;
        UserInfo * joiner = m_mapIDToUserInfo.find(rq->m_UserID);

        STRU_ROOM_MEMBER_RQ joinrq;
        joinrq.m_UserID = rq->m_UserID;
        strcpy(joinrq.m_szUser , joiner->m_userName);
        //給自己用於更新自己的信息
        SendData( clientfd , (char*)&joinrq , sizeof (joinrq));

        //根據房間號拿到房間成員列表
        list<int> lstRoomMem = m_mapIDToRoomid.find(rq->m_RoomID);
        //互換信息
        for( auto ite = lstRoomMem.begin() ; ite!=lstRoomMem.end() ; ++ite)
        {
            int Memid = *ite;
            if( !m_mapIDToUserInfo.IsExist(Memid)) return;
            UserInfo * memInfo = m_mapIDToUserInfo.find(Memid);

            STRU_ROOM_MEMBER_RQ memrq;
            memrq.m_UserID = memInfo->m_id;
            strcpy(memrq.m_szUser , memInfo->m_userName);

            //把加入人的信息發送給每一個房間內成員
            SendData(memInfo->m_sock , (char*)&joinrq ,sizeof (joinrq));
            //房間內成員每個人信息發給加入人
            SendData(clientfd , (char*)&memrq, sizeof (memrq));
        }
        //加入人，添加到房間列表
        lstRoomMem.push_back( rq->m_UserID);
        m_mapIDToRoomid.insert(rq->m_RoomID , lstRoomMem);
```

## 修改四：VideoFrameRq 视频帧转发（对应问题5：wdg_Usershow 不同步画面）

### 问题原因
原代码中：
1. `if( !m_mapIDToRoomid.IsExist(userid)) continue;` —— 检查逻辑错误（同上）
2. `SendData( userinfo->m_audiofd , szbuf , nlen);` —— **视频帧发送到了音频 fd（m_audiofd），而不是视频 fd（m_videofd）！** 客户端的视频接收线程监听的是 m_videofd，发到 m_audiofd 自然收不到视频帧，导致 wdg_UserShow 不同步画面。

### 原代码（第 318-340 行附近）

```cpp

    {
        //看是否在線，轉發

        //SendData( userinfo->m_sock , szbuf , nlen);
        SendData( userinfo->m_audiofd , szbuf , nlen);

    }
}
```

## 修改五：VideoRegister 视频注册（对应问题5：wdg_Usershow 不同步画面）

### 问题原因
原代码 `info->m_audiofd = clientfd;` —— **视频注册却更新了音频 fd（m_audiofd），导致视频 fd（m_videofd）始终为 0！** VideoFrameRq 中发送视频帧到 m_audiofd，客户端视频线程收不到。

### 原代码（第 357-368 行附近）

```cpp
//視頻注冊
void CLogic::VideoRegister(int clientfd, char *szbuf, int nlen)
{
    printf("clientfd:%d VideoRegister\n", clientfd);
    //拆包
    STRU_VIDEO_REGISTER *rq = (STRU_VIDEO_REGISTER * )szbuf;
    int userid = rq->m_userid;
    //根據userid找到節點 更新fd
    if( m_mapIDToUserInfo.IsExist(userid) )
    {
        UserInfo * info = m_mapIDToUserInfo.find(userid);
        info->m_audiofd = clientfd;
    }
}
```

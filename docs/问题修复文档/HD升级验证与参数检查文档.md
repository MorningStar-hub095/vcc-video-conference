## 四、摄像头模式手动验证

### 4.1 验证前置条件

| 条件 | 要求 |
|------|------|
| 服务端 | 已启动并正常运行 |
| 客户端 | 两个实例，分别登录不同账号 |
| 房间 | 两个客户端加入同一房间 |
| 摄像头 | 支持 1280×720 分辨率 |
| 网络 | 局域网或带宽 ≥ 5Mbps |

### 4.2 参数验证步骤

#### 步骤1：验证摄像头采集分辨率

**操作：**
1. 客户端A登录后进入房间
2. 点击"开启视频"按钮
3. 观察客户端A本地预览画面

**预期：**
- 画面宽高比为 16:9（无变形，人物比例正常）
- 画面清晰度明显优于 SD（640×480）
- 无"人物变扁"现象

**验证代码生效：**
- `videoread.cpp:136-137` 的 `cap.set(CAP_PROP_FRAME_WIDTH, 1280)` 生效
- `videoread.cpp:58` 的 `Qt::KeepAspectRatio` 生效

#### 步骤2：验证 H264 编码参数

**操作：**
1. 在 `h264encoder.cpp:init` 函数中添加临时日志（可选）：
   ```cpp
   qDebug() << "编码参数:" << width << "x" << height << "bitrate=" << bitrate
            << "preset=faster crf=20 profile=high";
   ```
2. 开启视频后查看客户端调试输出

**预期日志：**
```
H264Encoder: using encoder libx264 (verified by avcodec_open2)
H264Encoder: init success, 1280 x 720 @ 30fps encoder:libx264 buffer:av_frame_get_buffer sws:sws_scale
```

**验证参数：**
| 参数 | 预期值 | 验证方式 |
|------|--------|----------|
| 编码器 | libx264（或 h264_nvenc/h264_qsv） | 日志 "using encoder" |
| 分辨率 | 1280×720 | 日志 "1280 x 720" |
| 帧率 | 30fps | 日志 "@ 30fps" |
| preset | faster | 代码 h264encoder.cpp:74 |
| crf | 20 | 代码 h264encoder.cpp:76 |
| profile | high | 代码 h264encoder.cpp:77 |
| 码率 | 3000000 | 代码 ckernel.cpp:530 |

#### 步骤3：验证网络传输

**操作：**
1. 客户端B查看客户端A的视频画面
2. 使用任务管理器或 `netstat -e` 监控网络流量

**预期：**
- 客户端B能看到客户端A的视频画面
- 画面无马赛克、无卡顿
- 网络带宽约 375 KB/s（摄像头视频流）
- H264 编码路径生效（非 JPEG）

**验证参数：**
| 参数 | 预期值 | 验证方式 |
|------|--------|----------|
| TCP缓冲区 | 1MB | 代码 TcpClient.cpp:78,84 |
| H264分片大小 | 8192字节 | 代码 packdef.h:67 |
| 分片重组超时 | 150ms | 代码 packdef.h:69 |
| 视频帧转发 | 正常 | 服务端日志 "VideoFrameH264Rq" |

#### 步骤4：验证宽高比修复（重点）

**操作：**
1. 客户端A开启摄像头
2. 对准人脸或标准比例物体（如圆形）
3. 客户端B观察接收到的画面

**预期：**
- ✅ 人脸比例正常（不矮、不宽）
- ✅ 圆形物体仍为圆形（非椭圆）
- ✅ 无"人物变扁"现象

**对比验证：**
| 场景 | 修复前（IgnoreAspectRatio） | 修复后（KeepAspectRatio+采集分辨率设置） |
|------|---------------------------|----------------------------------------|
| 摄像头支持1280×720 | 画面正常但可能轻微变形 | ✅ 画面完全正常 |
| 摄像头不支持1280×720 | 画面变形（人物变扁） | ✅ 画面保持原比例，留黑边（不变扁） |

#### 8.1.1 本次新增修改验证（代码审查）

| 文件 | 修改内容 | 审查维度 | 验证结果 | 详细说明 |

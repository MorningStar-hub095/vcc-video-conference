一套可运行的桌面 C/S 视频会议系统（注册登录、房间、语音、视频、桌面共享） 网页应用 —— 没有在线 demo，客户端是 Windows 桌面程序
约 20k 行、单人从协议设计到部署运维独立完成的学习作品 生产级软件 —— 未做并发压测，请勿商用
带完整工程化：Docker 部署、健康探针、隔离冒烟、SQL 注入回归、版本化迁移与回滚 腾讯产品的仿制品 —— 与腾讯公司无任何关联

技术亮点

  1. 自定义二进制应用层协议：13 类包、帧格式 [int32 小端长度][包体]，双端补齐包长合法性校验（≤0 或 >1MB 直接丢弃），修复"异常包长可被未认证客户端耗尽内存"的缺陷。
  2. 三级音频处理链路：SDL2 采集 → WebRTC VAD 静音断流 → Opus 48kHz/VOIP 编码，另集成 Speex AEC 回声消除。
  3. 视频链路：摄像头/屏幕采集 → OpenCV 处理（含人脸检测）→ H.264 硬编码优先 + PLI 关键帧请求重传。
  4. 工程化门禁：本地 ci-local.sh 四步门禁与 CI 同源、隔离冒烟栈（生产库零污染）、bcrypt 口令散列、mTLS 双向认证 + CRL 吊销体系。

30 秒了解

  • 快速体验：下载 Release 中的客户端 zip → 解压 → 改 config.ini 的 ip 为你部署的服务端地址 → 双击 vcc-client.exe
  • 服务端部署（方式一：源码编译，推荐）：
sudo apt-get install build-essential libmysqlclient-dev
cd server
~/Qt5.9.9/5.9.9/gcc_64/bin/qmake PlayerHallServer.pro
make -j4
mysql -h127.0.0.1 -u用户名 -p < deploy/schema.sql   # 建库建表
export DB_IP=127.0.0.1 DB_USER=用户名 DB_PWD=口令 DB_NAME=vcc
./PlayerHallServer      # 监听 TCP 8000 + UDP 1234

也有 Docker Compose 一键部署（deploy/deploy.sh，可选 mTLS 网关），适合有 Docker 环境的服务器场景，详见 README · 部署。

📌 演示视频待录制：将展示双端注册登录 → 建房进房 → 音频互通 → 视频互通 → 桌面共享的完整 60~90 秒流程。

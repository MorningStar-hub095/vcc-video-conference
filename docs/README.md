# 项目文档库

本目录收录 VCC 视频会议项目的全部技术文档与学习资料。项目早期内部代号 `WeChat`（与腾讯公司无关），文档中如出现旧称请以 VCC 为准。

> 阅读提示：架构图 HTML 使用 CDN 加载 Mermaid，需联网打开；PDF 为对应 Markdown 的排版版本。

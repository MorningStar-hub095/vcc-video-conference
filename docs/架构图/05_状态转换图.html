六、音频静音状态机 (WebRTC VAD)

基于 WebRTC VAD 的静音检测状态机：audioCallback 每帧（20ms）调用 WebRtcVad_Process 判定有声/静音，并通过 calculateRMS 更新噪声能量 m_noiseLevel。采用连续 3 帧（≈60ms）状态平滑确认，避免瞬态抖动误触发。状态切换时 Q_EMIT SIG_muteStateChanged 跨线程通知 ckernel → RoomDialog 联动 UI。另由 QTimer（主线程）每 5 秒触发 slot_adjustVadMode，按 m_noiseLevel 的 EMA（α=0.95）三档动态选择 VAD 模式：RMS < 0.02 → 模式1(宽松)、< 0.10 → 模式2(中等)、≥ 0.10 → 模式3(严格)。
stateDiagram-v2 [*] --> 有声 : 构造后默认(m_currentMuteState=false) 有声 --> 静音 : 连续3帧 VAD=0(≈60ms确认) note right of 静音 : 进入静音伴随动作:
Q_EMIT SIG_muteStateChanged(true)
→ ckernel::slot_muteStateChanged(true)
→ RoomDialog::updateMuteStatus(true)
→ cb_audio 显示“音频(无声)” + 灰色 + tooltip
注: 静音帧仍 memset 清零后送 Opus 编码 静音 --> 有声 : 连续3帧 VAD=1(≈60ms确认) note left of 有声 : 退出静音伴随动作:
Q_EMIT SIG_muteStateChanged(false)
→ ckernel::slot_muteStateChanged(false)
→ RoomDialog::updateMuteStatus(false)
→ cb_audio 恢复显示“音频”

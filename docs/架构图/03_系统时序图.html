五、静音检测与 UI 联动时序

AudioRead 在 SDL 采集回调中完成 WebRTC VAD 检测与 RMS 能量计算，经连续 3 帧状态平滑确认后，通过 SIG_muteStateChanged 信号（Qt::QueuedConnection 跨线程）通知 ckernel，再由 ckernel 调用 RoomDialog::updateMuteStatus 更新音频按钮的文本、样式与 tooltip。另由 QTimer 每 5 秒触发 slot_adjustVadMode，按噪声 RMS 的 EMA 动态切换 VAD 灵敏度模式。
sequenceDiagram participant SDL as SDL采集线程 participant AR as AudioRead
(音频采集) participant CK as ckernel
(核心控制器) participant RD as RoomDialog
(房间界面) SDL->>AR: audioCallback(stream, 1920字节) AR->>AR: WebRtcVad_Process(48kHz, 960采样) AR->>AR: calculateRMS(samples, 960) 更新 m_noiseLevel AR->>AR: 状态平滑(连续3帧确认, ≈60ms) AR-->>CK: SIG_muteStateChanged(isMute)
(Qt::QueuedConnection 跨线程) CK->>CK: slot_muteStateChanged(isMute) CK->>RD: updateMuteStatus(isMute) alt isMute=true (进入静音) RD->>RD: cb_audio 显示“音频(无声)” + 灰色 + tooltip else isMute=false (退出静音) RD->>RD: cb_audio 恢复显示“音频” end Note over AR: QTimer(主线程)每5秒触发 slot_adjustVadMode
读 m_noiseLevel 的 EMA(α=0.95) 动态切换 VAD 模式
RMS < 0.02 → 模式1(宽松) | < 0.10 → 模式2(中等) | ≥ 0.10 → 模式3(严格)

二、用例详细说明

用例名称 前置条件 基本流程 异常流程
UC1 登录系统已注册账号，服务端在线1.输入手机号+密码 → 2.MD5加盐哈希 → 3.TCP发送 → 4.服务端验证 → 5.返回结果 → 6.进入主界面手机号不存在/密码错误/网络超时
UC2 注册账号服务端在线1.输入手机号+密码+用户名 → 2.MD5哈希 → 3.TCP发送 → 4.插入数据库 → 5.返回成功手机号已注册
UC3 创建房间已登录1.点击创建房间 → 2.服务端分配roomId → 3.返回成员列表 → 4.显示房间界面创建失败（服务端异常）
UC4 加入房间已登录1.输入房间号 → 2.正则校验 → 3.TCP发送 → 4.服务端查找房间 → 5.返回成员列表 → 6.显示房间界面房间不存在/房间号格式错误
UC5 退出房间在房间内1.点击退出 → 2.TCP发送离开请求 → 3.服务端广播 → 4.清理本地资源 → 5.返回主界面-
UC6 开启摄像头在房间内1.点击开启 → 2.OpenCV打开摄像头 → 3.定时采集帧 → 4.H.264编码 → 5.TCP发送摄像头不可用（自动回退DirectShow/MSMF）
UC7 开启麦克风在房间内1.点击开启 → 2.SDL打开采集设备 → 3.回调采集20ms → 4.VAD静音检测 → 5.Opus编码 → 6.TCP发送麦克风不可用
UC8 桌面共享在房间内1.点击开启 → 2.Qt Screen截图 → 3.缩放1024x768 → 4.H.264编码 → 5.TCP发送截图失败
UC10 音视频通话在房间内，音视频已开启1.持续采集编码 → 2.TCP传输 → 3.服务端转发 → 4.解码 → 5.音视频同步 → 6.渲染/播放网络断开/编解码失败
UC12 音视频同步音视频数据正在接收1.音频帧更新audio_clock → 2.视频帧与audio_clock比对 → 3.超前等待/落后追赶 → 4.同步渲染时钟超时失效（5秒无数据）

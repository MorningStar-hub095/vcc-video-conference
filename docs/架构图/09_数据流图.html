音频数据流关键节点：
1. SDL采集回调（20ms周期，SDL线程驱动，替代QTimer轮询）
2. WebRTC VAD静音检测（静音帧清零，Opus DTX进一步降低带宽）
3. Opus编码（48kHz VOIP模式，DTX+FEC启用，32kbps目标码率）
4. SDL回调解码播放（生产者-消费者模型，mutex保护队列）

视频数据流关键节点：
1. OpenCV采集（多后端回退：默认→MSMF→DirectShow）
2. FFmpeg H.264编码（硬件回退：NVENC→QSV→libx264）
3. 4KB分片传输（H264专用协议包头，支持分片重组）
4. AVSyncManager同步（音频主时钟，10ms阈值）
5. OpenGL YUV渲染（VAO/VBO+GLSL现代管线，GPU端YUV→RGB）

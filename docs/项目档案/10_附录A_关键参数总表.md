## 附录 A 关键参数总表

### A.1 音频参数
| 参数 | 值 | 说明 |
|------|-----|------|
| 采样率 | 48000 Hz | SDL 采集/播放 |
| 帧长 | 960 samples (20ms) | 960/48000=0.02s |
| 帧字节 | 1920 字节 | 960×2(int16) |
| Opus 码率 | 32 kbps | 宽带语音 |
| Opus DTX 静音码率 | ~1 kbps | 不连续传输 |
| Opus 复杂度 | 5 | 平衡 CPU |
| VAD 初始模式 | 2 | VoIP 推荐 |
| VAD EMA α | 0.95 | `0.95×old + 0.05×new` |
| VAD 评估周期 | 5 秒 | QTimer |
| 模式1触发 | EMA < 0.02 | 宽松（安静） |
| 模式2触发 | 0.02 ≤ EMA < 0.10 | 中等 |
| 模式3触发 | EMA ≥ 0.10 | 严格（嘈杂） |
| 状态平滑帧数 | 3 帧 (60ms) | MUTE_CONFIRM_THRESHOLD |

### A.2 视频参数
| 参数 | 值 | 说明 |
|------|-----|------|
| 摄像头分辨率 | 1280×720 | HD |
| 摄像头帧率 | 30 fps | QTimer 23ms |
| 摄像头码率 | 3.0 Mbps | H264 |
| 桌面分辨率 | 1920×1080 | FHD |
| 桌面帧率 | 20 fps | QTimer 50ms |
| 桌面码率 | 4.0 Mbps | H264 |
| H264 分片 | 8192 字节 | H264_FRAGMENT_SIZE |
| 重组超时 | 150 ms | H264_REASSEMBLE_TIMEOUT |
| JPEG 回退质量 | 75 | H264 失败时 |
| 编码防堆积 | m_encodingPending | 上帧未编完跳帧 |
| 发送延迟丢弃 | 2000 ms | slot_SendVideo |
| SD 回退（预留） | 640×480 / 1.2 Mbps | 弱网参数 |

| TCP 发送缓冲 | 1 MB | 客户端/服务端 |
| TCP_NODELAY | 启用 | 降低小包延迟 |

| epoll MAX_EVENTS | 4096 | epoll_create |
| listen backlog | 128 | |
| epoll_wait 超时 | 1000 ms | |
| EAGAIN 重试 | 1000 us | usleep(1000) |
| 线程池 min | 10 | 常驻 |
| 线程池 max | 200 | 动态扩容上限 |
| 线程池队列 | 50000 | 环形队列 |

### A.4 数据库参数
| 参数 | 值 |
|------|-----|
| 表名 | t_user |
| 字段 | id, tel, password, name, email, icon, feeling |
| 默认 icon | 1 |
| 默认 feeling | "比较懒，什么也没写" |
| 字符集 | utf8 |
| 连接方式 | 单连接 + pthread_mutex |
| 密码哈希 | MD5 + 固定盐（⚠️ 待升级 bcrypt） |

### A.5 编解码器参数
| 参数 | 值 | 说明 |
|------|-----|------|
| H264 preset | faster | 速度优先 |
| H264 tune | zerolatency | 零延迟（无 B 帧） |
| H264 crf | 23 | 质量与码率平衡 |
| H264 编码器回退链 | nvenc→qsv→libx264→JPEG | 运行时探测 |
| JPEG 回退质量 | 75 | H264 失败时 |
| Opus application | VOIP | 语音通话模式 |
| Opus bitrate | 32000 bps | 宽带语音 |
| Opus complexity | 5 | CPU 平衡（0-10） |
| Opus DTX | 启用 | 静音降至 ~1kbps |
| Opus FEC | 启用 | 前向纠错抗丢包 |
| VAD 采样率 | 8000 Hz | WebRTC VAD 支持 8/16/32kHz |
| VAD 帧长 | 20 ms | 160 samples @8kHz |

### A.6 音视频同步参数
| 参数 | 值 | 说明 |
|------|-----|------|
| 同步策略 | 音频主时钟 | 视频同步到音频 |
| 同步算法 | 时间戳对齐法 | `computeSyncDelay` 计算 waitMs |
| SYNC_THRESHOLD_US | 10000 微秒（10ms） | 参考 ffplay 标准值 |
| MAX_WAIT_MS | 100 ms | 视频等待上限，防 UI 卡死 |
| CLOCK_TIMEOUT_MS | 5000 ms | 5 秒无音频视为断流 |
| frameDelay | 33333 微秒 | 30fps 帧间隔，推进 videoClock |
| 时间戳来源 | 系统时钟 | `getCurrentTimeUs()` 微秒 |
| 上下文结构 | SyncContext | 每用户独立 audioClock/videoClock |
| 线程安全 | std::mutex | SDL 线程 + UI 线程并发保护 |
| 唇音同步感知阈值 | ±80 ms | ITU-T G.107 推荐 |
| 音画同步可接受范围 | ±200 ms | 人眼可接受上限 |

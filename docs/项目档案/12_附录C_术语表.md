## 附录 C 术语表

| 术语 | 含义 |
|------|------|
| VAD | Voice Activity Detection，语音活动检测 |
| GMM | 高斯混合模型，WebRTC VAD 的统计判决基础 |
| EMA | 指数移动平均，用于噪声水平平滑估计 |
| DTX | Discontinuous Transmission，不连续传输，静音时降码率 |
| FEC | Forward Error Correction，前向纠错 |
| PLI | Picture Loss Indication，关键帧请求 |
| SFU | Selective Forwarding Unit，选择性转发单元 |
| MCU | Multipoint Control Unit，多点控制单元（混流） |
| GOP | Group of Pictures，I 帧间隔 |
| AVSync | 音视频同步 |
| EPOLLONESHOT | epoll 一次性事件，保证同 fd 单线程处理 |
| Qt 隐式共享 | 浅拷贝共享数据，写时复制，跨线程易致 use-after-free |
| BT.601 | YUV↔RGB 转换标准（SDR 标清） |
| BT.709 | YUV↔RGB 转换标准（HD 高清） |
| ASR | Attack Surface Reduction，Windows Defender 攻击面削减规则 |
| ICE | Interactive Connectivity Establishment，NAT 穿透框架 |
| STUN | Session Traversal Utilities for NAT，NAT 类型探测 |
| TURN | Traversal Using Relays around NAT，NAT 中继转发 |
| SRTP | Secure RTP，加密实时传输协议 |
| DTLS | Datagram Transport Layer Security，UDP 版 TLS |
| GCC | Google Congestion Control，WebRTC 拥塞控制算法 |
| SIMD | Single Instruction Multiple Data，单指令多数据（CPU 向量优化） |
| COM | Component Object Model，Windows 组件对象模型 |
| Meyers' Singleton | C++11 局部静态变量实现的线程安全单例模式 |
| YUV420P | YUV 4:2:0 Planar，三平面分离（Y/U/V 独立缓冲） |
| RMS | Root Mean Square，均方根（音频能量度量） |
| MOS | Mean Opinion Score，语音质量主观评分（1-5） |
| LT | Level Triggered，epoll 水平触发模式 |
| ET | Edge Triggered，epoll 边缘触发模式 |
| QueuedConnection | Qt 跨线程信号槽连接方式（事件队列投递） |
